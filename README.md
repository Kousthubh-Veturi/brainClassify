# 🧠 Brain Tumor Classifier 🏥💡  
🚀 **Personal Project by Kousthubh Veturi ** | 🔬 **Deep Learning and MLOps**  

---

## 🎯 What is this?
This is a **cutting-edge** 🦾 **brain tumor classification** web app that uses a **Vision Transformer (ViT)** 🏋️‍♂️ trained from **scratch** on the **BraTS 2021 dataset**.  

The app allows users to:  
✅ **Upload MRI images** 🖼️  
✅ **Get AI-based predictions** 🤖  
✅ **Provide feedback to improve the model** 🔄  
✅ **Continuously retrain the model** to get **smarter over time** 🧠✨  

---

## 🏗️ Tech Stack
This project is a **full-stack AI-powered web app** combining **deep learning, cloud computing, and DevOps**.  

### 💻 **Backend**
- ⚡ **FastAPI** (High-performance API)  
- 🧠 **TensorFlow + Vision Transformer** (Deep Learning)  
- 📡 **TensorFlow Serving** (Model Deployment)  
- ☁️ **AWS S3** (Cloud Storage)  

### 🎨 **Frontend**
- ⚛️ **React** (Modern UI Framework)  
- 🎨 **TailwindCSS** (Sleek design)  
- 📡 **Axios** (API Requests)  

### 📦 **DevOps & Deployment**
- 🐳 **Docker** (Containerization)
